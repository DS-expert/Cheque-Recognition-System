# Cheque Recognition System 

Cheque recognition sytem use for to recognize and convert money digit into digital output. Our work is to train model to recognize various money digit on the cheque. 

### Use of this System
 - This system is mostly use for digital system. To recognize the amount digit and sometime to check the signature of owner if is not a forged signature.

### How to Contribute in Project?
- First you need to have dataset in your own system.
[Dataset link](https://www.kaggle.com/datasets/jdranpariya/cheque-data/data).

- Second clone the github repository `github clone https://github.com/DS-expert/Cheque-Recognition-System.git`.

- Third make your own branch if you want to contribute properly `git branch your_name/scope` for example `github branch arshad/preprocessing`.

- Next go to your repository in github to open pull request and type your contribution. What you do? and where?
